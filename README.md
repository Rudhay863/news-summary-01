# World news summary — 11 November 2026

Entry for the make.fun `news-summary-01` bounty: a program that writes the
best summary of the world's news of Wednesday 11 November 2026.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`, then
read `out/entry.txt`. The summary is fixed text (1,952 characters), so every
run writes the same bytes. Python 3.13 standard library only, no network.
